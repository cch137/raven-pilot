請查閱 {{target}} 的最新官方文檔與資源，整理其核心概念、特性、結構與典型使用情境，撰寫成一份緊湊的 Markdown 文檔。要求如下：

- 每個知識點僅需幾句精要說明，以確保高效使用 tokens
- 若涉及程式碼，以簡短 code block 示範關鍵用法
- 以最低限度展示其特色與應用場景

此文檔用於更新 AI Agent 的知識庫——由於大多數 LLM 存在知識截止日期，面對新興或非主流技術時常出錯，因此需要深度調研，撰寫一份全面且精練的參考文檔。
